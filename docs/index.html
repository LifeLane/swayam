Product Overview

SWAYAM GPT is an advanced Android application that leverages on-device large language models (LLMs) to provide an interactive, context-aware AI assistant. It integrates memory, document intelligence, and autonomous agents directly into your device.

Core Features

🔒 Complete Privacy

100% on-device inference using MediaPipe LiteRT. No data leaves your device unless you explicitly configure an external provider.

🧠 Memory Vault

Securely index and recall personal notes, preferences, and long-term context using an encrypted local vector store.

📄 Document RAG

Index local documents and perform Retrieval-Augmented Generation (RAG) completely offline to ground AI responses.

🤖 Agent Architecture

Support for multi-step autonomous execution and tool use, capable of extending functionality through MCP (Model Context Protocol).

Download & Testing

You can download the latest builds from the GitHub Releases page. To test:

  1. Download the `app-release.apk` file.
  2. Enable "Install from Unknown Sources" in your Android settings.
  3. Install the APK.
  4. On first launch, navigate to "Settings -> AI Models" to download a compatible quantized GGUF model for your device.
